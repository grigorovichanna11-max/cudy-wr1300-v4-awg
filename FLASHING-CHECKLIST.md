# Cudy WR1300 v4 — безопасное обновление и восстановление

**Состояние на 21 октября 2026 года.** Это инструкция для конкретного Cudy **WR1300 hardware v4**, не для WR1300 v1–v3, WR1300S или других моделей.

## Наш образ

- OpenWrt **25.12.4** (ramips/mt7621) + AmneziaWG **3.1**
- Название: `openwrt-ramips-mt7621-cudy_wr1300-v4-squashfs-sysupgrade.bin`
- Размер: **8 389 195 байт**
- SHA-256: `09b3a94dc2d0912b9dc3d2819f6d3daf67e641a55e187d7b3352bbd35570ff05`
- GitHub Actions, успешная сборка №6: https://github.com/grigorovichanna11-max/cudy-wr1300-v4-awg/actions/runs/39471615125
- Файл скачивать из **Artifacts** данного запуска (пока артефакт не истёк); ZIP содержит образ, SHA256SUMS и BUILD-INFO.txt.
- Embedded sysupgrade metadata: `board: cudy_wr1300-v4`, `new_supported_devices: [cudy,wr1300-v4, cudy,wr1300, R30]`. В metadata явно заявлена несовместимость конфигурации swconfig → DSA.

**Важно:** успешная компиляция и корректная SHA-256 не гарантируют корректную загрузку на конкретном устройстве. Наш образ пока НЕ проверен физической прошивкой.

## Что сейчас установлено

По предыдущей диагностике — сторонняя сборка OpenWrt **SNAPSHOT**, ядро **6.18.28**, `apk`, LAN `192.168.1.1`. Переход SNAPSHOT → 25.12.4 не следует рассматривать как обычное обновление с безопасным переносом конфигурации. Версия ядра на новой прошивке может быть иной.

## Подготовка без перепрошивки

1. Подключить ПК **кабелем в LAN-порт** Cudy; иметь доступ к настройкам основного роутера/интернету без Cudy.
2. В текущем LuCI открыть **System → Backup / Flash Firmware → Generate archive**. Сохранить архив резервной копии на ПК. Старый бэкап от заводской Cudy **не является** бэкапом нынешней OpenWrt.
3. Отдельно сохранить/сфотографировать текущие настройки **LAN, WAN, Wi‑Fi, DNS, DHCP**, параметры VPN и пароли. Бэкап старой версии **не восстанавливать целиком** в новую, если конфигурация несовместима.
4. Сохранить **рабочий sysupgrade-образ нынешней OpenWrt**, чтобы был путь обратно. Предыдущий образ, из которого ставили SNAPSHOT: https://github.com/GuoShuangyan/Openwrt-Cudy-WR1300-v4 (перед использованием проверить, что это именно установленная сборка и она для v4).
5. Для аварийного восстановления сохранить **официальную прошивку конкретно WR1300 4.0**, распаковав ZIP: https://www.cudy.com/ru-ru/pages/download-center/wr1300-4-0 . Не подменять её образами для v3/v2 и не выдавать ZIP за `recovery.bin`.
6. Проверить аппаратную модель и target на странице **Status → Overview**. При возможности безопасный read-only тест через SSH с **тем же образом, загруженным в /tmp**: `sysupgrade -T /tmp/имя_образа.bin`; это **только проверка**, не прошивка. Тест не доказывает корректность дальнейшей загрузки. Не использовать `-F`.
7. Если обнаружена ошибка несовместимости типа устройства или неожиданная ошибка image check, **НЕ нажимать Force/Принудительно**. Сначала изучить причину.

## Как устанавливать после проверки

1. Через LAN (не через Wi‑Fi) открыть текущую LuCI → **System → Backup / Flash Firmware**.
2. Выбрать наш файл **`*-sysupgrade.bin`**, а не ZIP и не `*-flash.bin` заводской прошивки.
3. На экране проверки внимательно сверить устройство и предупреждения. При любом неожиданном несовпадении или требовании принудительно обойти проверку — **ОСТАНОВИТЬСЯ**.
4. При условии, что стандартная проверка совместимости прошла и согласован чистый переход, **снять галочку Keep settings / Сохранить настройки**. Это сбросит текущую конфигурацию.
5. Только после этого запускать прошивку. Во время записи/перезагрузки питание не отключать.
6. После чистой установки OpenWrt обычно доступна по `192.168.1.1`, Wi‑Fi может быть выключен. Подключаться по Ethernet, установить пароль администратора, восстановить сетевые параметры вручную, затем конфигурировать VPN.

**Нельзя** принудительно «протащить» настройки swconfig через DSA, а также прошивать по Wi‑Fi или принудительно при несовместимости платы.

## Восстановление при неудачной прошивке (подготовить заранее)

Официальная инструкция Cudy: https://docs.cudy.com/faq/10002_How_to_recover_Cudy_devices%27_firmware_via_TFTP/

1. Понадобятся **Ethernet-кабель, компьютер, TFTP-сервер и подходящая оригинальная прошивка для WR1300 v4**.
2. После распаковки официального архива убедиться, какой файл предназначен для восстановления. **Проверить указания для своей аппаратной/региональной ревизии**; нельзя слепо переименовывать произвольный образ.
3. Согласно Cudy, TFTP-сервер на ПК должен иметь адрес `192.168.1.88`, корректный файл восстановления называется `recovery.bin`.
4. ПК соединён кабелем с **LAN** роутера, TFTP-сервер запущен.
5. При отключённом питании зажать **RESET**, включить питание и удерживать до начала TFTP-передачи, после чего отпустить.
6. После передачи ждать завершения установки/перезагрузки, не отключать питание. Вернуть адаптер ПК с постоянного IP на автоматическое получение IP и проверить связь.

**Важно:** официальная инструкция общая для Cudy; до каких-либо рискованных шагов стоит дополнительно подтвердить, что bootloader именно имеющегося WR1300 v4 принимает этот файл. Метод TFTP — аварийная процедура, не гарантия восстановления при любом отказе.
